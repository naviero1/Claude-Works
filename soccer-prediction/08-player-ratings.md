# Player Ratings & Disruptor Reference (R32 teams)

Compiled 2026-06-27 from web research (Transfermarkt / FotMob / FBref-type sources, club
official). **EA FC 26 ratings are approximate cross-checks only** — the video game lags reality
and underrates non-European-league players. **Disruptor score (1–10)** is analyst judgment of how
much a player can single-handedly swing a tight knockout game (see the
[rubric](05-disruptor-rubric-and-worked-example.md)). Lines marked *unverified* should not be
treated as hard inputs.

## 3. Cohesion index (collective > sum of parts)
- **Morocco** — the benchmark: battle-tested spine (Bono–Aguerd–Amrabat–Hakimi–Brahim) + shootout
  temperament. *Caveat:* Regragui left after AFCON 2025; new coach, unsettled striker slot.
- **Iran** — disciplined low block + fast direct transitions to Taremi; elite qualifying defense.
  Very hard to beat in a low-scoring knockout; struggles if forced to chase a game.
- **Japan** — cohesion via fluid technical depth (not a low block); reshapes around absences, but
  Mitoma/Minamino out thins the creative ceiling.
- **Cape Verde** — debutants punching above weight on collective discipline; squad skews 35–36 in
  weaker leagues, so production is real but level-adjusted.
