# Gemini image requests

Checkpoint 1 status: no generation requested; no images generated.

**Nothing needed from Oscar for image production at this stage.** The proposed improvements explain relationships using existing content: annotation, process paths, comparison, feedback loops, approval boundaries, chronological rails, and one quantitative data-bar treatment. These are better constructed as accurate, editable PowerPoint objects than generated illustrations.

Beebop owns concept selection, source/evidence review, visual acceptance, and organization. Rocksteady builds the precise native objects only after approval. Existing successful assets are reused in place. No stock-image search, purchase, external upload, or assumed Gemini account access is required for this plan.

If an approved pilot identifies a real need for illustration, Beebop will submit a separate, complete request with stable asset code, exact slide, instructional purpose, measured box/aspect/pixels, palette/background, composition/negative space, required and forbidden elements, source references, filename, copy-ready Gemini prompt, observable acceptance criteria, and return instructions. Oscar approves that request before production. Returned candidates are inspected and stored separately from approved assets; uploading a candidate does not approve its slide treatment.
