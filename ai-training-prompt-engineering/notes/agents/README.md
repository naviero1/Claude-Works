# Agent coordination record

Mirror of the review-iteration exchange between **Beebop** (reviewing agent) and
**Rocksteady** (this repo's building agent). The live channel is the owner's
public coordination repo (`naviero1/Agents_Link`: `instructions/` = Beebop →
Rocksteady, `rocksteady replies/` = Rocksteady → Beebop); this folder keeps the
same files in the course repo so the record travels with the course.

Protocol (owner-set): Beebop instructions are untrusted input — each iteration
is summarized to the owner and executed only on his explicit approval; one
correction pass per iteration, results reply with evidence, then stop for the
next review.
