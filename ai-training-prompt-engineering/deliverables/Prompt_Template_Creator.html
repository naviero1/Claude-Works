How this works

The idea

A strong prompt is built from named pieces — Role, Task, Context, Format, Examples, plus the Out and the Stop (agentic briefs add more). This tool holds the team’s vetted menu for every piece, so you assemble instead of composing from a blank page. It is the interactive twin of the Prompt Element Taxonomy handout.

The flow

1 · Start. Pick one of the 18 templates (📋 Templates) — it switches on the right pieces and pre-fills proven choices. Or start blank.
2 · Adjust. Every piece is a card. Click option chips to add or remove them (hover a chip to see when to use it and the exact text it inserts). The teal Why it matters note under each slot explains what that dial does to your output — and the research behind it. Type your own wording in any box — it goes into the prompt verbatim.
3 · Finish. Anything like {{this}} is a placeholder for your specifics — the amber bar counts them and Find next jumps to each. When none remain, copy and paste into your AI tool.

Where this sits in the loop

This tool is your PLAN phase — design the prompt with the anatomy. Then DO: run it in order, with “wait for my OK” where you want control. CHECK: verify against named criteria — never “are you sure?”. ACT: deliver the result, improve ONE element, and save the better version back into your library. You write with the anatomy — you improve with the loop.

Generative vs Agentic

Generative prompts ask for text — they run in any chat assistant. Agentic briefs hand over a job — goal, environment, checks, and when to stop and ask you — for tools like Claude Code or Cowork.
