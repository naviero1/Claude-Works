# Plain-language exercise pack (reference exercise — Explain a topic clearly)

One worked demonstration topic plus three self-study variations. In the current 60-minute run this exercise lives in the reference layer (deck appendix; workbook tab 5-Explain-Clearly) — no live slot. Each file contains a
short SOURCE text and a SAMPLE plain-language explanation produced with the
reusable prompt below. All material is generic teaching content — no company data.

## The reusable prompt

> Using [source], explain [topic] so a reader at a fifth-grade reading level can
> understand it. State the main idea first. Use familiar words, short sentences,
> meaningful headings, and one concrete example. Define necessary technical terms
> when first used. Use an analogy only if it is accurate, and explain where it
> stops being useful. Preserve important conditions and uncertainty. Do not invent
> facts or use a childish tone. End with three comprehension questions and a short
> answer key. Check the explanation against the source and identify any
> simplification that changes the meaning.

## How to check the result (acceptance evidence)

- A representative reader can state the main idea after one read.
- Every technical term that survives is defined at first use.
- The analogy's limit is stated ("where the picture stops working").
- Conditions and uncertainty from the source survive the simplification —
  compare sentence by sentence; a missing condition is a meaning change.
- The three questions are answerable from the text alone.
- Tone check: clear adult language; nothing condescending or childish.
- Readability scores (e.g., Flesch-Kincaid) are supporting evidence only —
  a score is not proof a real reader understands.
