# Deliverables

The five artifacts of **From Prompts to Agents**. Everything in `deliverables/` is
participant-facing and self-contained; everything else in this package is support
material, indexed in `REFERENCES.md`. All names, companies, and numbers are
fictional and generated for practice.

| # | File | What it is |
|---|---|---|
| 1 | `deliverables/From_Prompts_to_Agents_Facilitated_60_Minute.pptx` | **The presentation.** The 60-minute facilitated course: 70 live slides (30 min foundations + 32 min protected application) plus a 31-page reference appendix. Speaker notes on every slide carry MODE / TIME / PURPOSE / LAND THIS / SAY / DO / BRIDGE / IF LATE. |
| 2 | `deliverables/Course_Workbook.xlsx` | **The course workbook.** Open its INDEX tab first. The fictional supplier dataset (raw + checked), the five course task tabs `1-Analyze-Data … 5-Explain-Clearly` with staged prompts and self-checks, and two instructor key tabs. |
| 3 | `deliverables/Prompt_Template_Creator.html` | **The prompt creator.** Task-first builder: pick one of the five task families, choose requirements (each with its acceptance check), and the prompt assembles — editable, offline, single file. The full element taxonomy sits behind "Advanced". |
| 4 | `deliverables/From_Prompts_to_Agents_Course.pdf` | **The course PDF.** The extended written edition of the course, cover to cover: foundations, prompt engineering as requirements writing, the five worked tasks, agentic delegation, reusable prompts, and the reference appendix. For self-study or review after the live session. |
| 5 | `deliverables/From_Prompts_to_Agents_Cheat_Sheet.pdf` | **The course cheat sheet.** One printable page: the requirement skeleton, the 14-type menu, the quality bar, a before/after example, acceptance checks, and ASK vs DELEGATE. |

## How they connect

The presentation teaches; the workbook is where the five tasks are done; the
course PDF is the same course in book form; the cheat sheet is the one-page
distillation; the prompt creator turns the course's requirement menus into
reusable prompts. One fictional supplier case runs through all five.

Support files, prepared fallbacks, instructor material, and editable sources are
indexed in `REFERENCES.md`.
