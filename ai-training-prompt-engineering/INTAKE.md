# Intake checklist — what to collect to refine the taxonomy & tools

Drop anything collected into `notes/intake/` (create per-item subfolders as convenient).
Redact freely — structure matters more than the sensitive values. Each item lists what it feeds.

## Tier 1 — internal reality (highest value)

- [ ] **Real prompts** — 15–30 actual prompts teammates typed (any tool), lightly redacted.
      → gap analysis vs. the taxonomy; new options mined from real usage.
- [ ] **Recurring-deliverables inventory** — per person: deliverable, cadence, sources, audience.
      → real presets: one saved instance per actual job.
- [ ] **AI policy + approved-tool list** (the actual documents).
      → encode real data classes and tool names into Constraints / Confidentiality / Environment options.
- [ ] **House glossary** — each metric as used here: numerator, denominator, grain, inclusions/exclusions.
      → a committed GLOSSARY.md every template references.
- [ ] **Known data quirks** — per system (exports, sheets, masters): the quirk and the rule applied.
      → replaces the generic quirk options with ours.
- [ ] **Corporate deck template + one gold-standard past deliverable.**
      → G5/A2 continuity constraints; training's "what good looks like."
- [ ] **What's licensed/enabled** — Copilot tier, Excel Agent Mode on?, Claude plan, internal-assistant features.
      → per-option availability marks.

## Tier 2 — usage feedback

- [ ] **Builder pilot (3–5 people, 1 week):** which attribute confused you? which options did you pick? what did you type in custom boxes?
      → wording fixes; custom text promoted to options.
- [ ] **Failure stories** — 2–3 cases where AI output caused rework or embarrassment.
      → mapped to missing elements/options; personalizes the training's evidence.

## Tier 3 — gated product content (screenshots suffice)

- [ ] Copilot Prompt Gallery: full **Task** and **Job type** filter lists.
- [ ] Anthropic Console **prompt improver** output for any one prompt (paste result).
- [ ] ChatGPT Canvas **reading-level** and **length** slider labels.

## Tier 4 — the books' missing chapters (notes/photos of frameworks are enough)

- [ ] Berryman & Ziegler — **Ch. 6** (assembling the prompt: context budget, snippet prioritization) → Context element.
- [ ] Huyen, *AI Engineering* — **Ch. 5** (prompt engineering) and **Ch. 6** (RAG & agents) checklists → both branches.
- [ ] Phoenix & Taylor — **Evaluate Quality** and **Divide Labor** chapters → techniques layer.

**Skip:** anything on the public web / arXiv / vendor docs — already captured with sources in `notes/research/`.
